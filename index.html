JavaScript 调用

页面将生成器公开为 window.UAGenerator，可直接接入测试脚本。

const result = UAGenerator.generate({
  browser: 'chrome',
  platform: 'android',
  deviceId: 'pixel-10-pro-xl',
  osId: 'android-16',
  version: '152.0.7977.42',
  mode: 'legacy'
});

console.log(result.ua);
console.log(result.clientHints);

用于兼容性测试、日志构造与设备模拟。UA 只能描述客户端声明，不能证明真实硬件身份。
